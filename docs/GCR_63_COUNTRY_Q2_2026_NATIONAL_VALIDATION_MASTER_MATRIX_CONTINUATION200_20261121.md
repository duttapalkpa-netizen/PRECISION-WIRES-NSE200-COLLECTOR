## Status semantics

- `NOT_STARTED`: no country-specific national-source task/report located in the bounded repository search.
- `SOURCE_FOUND`: official source/locator identified; required Q2 separate national portfolio transaction legs not captured.
- `DATA_CAPTURED`: national Q2 leg values have been reported/captured in an existing report; per-leg and vintage gates remain individually represented in the CSV.
- `ASSET_PASS` / `LIABILITY_PASS`: use only when exactly that leg independently passes its documented source/concept/unit/sign/rounding gate. CSV records each leg gate independently.
- `VINTAGE_PASS`: not awarded merely because publication dates are close or values round identically; exact revision/vintage bridge required.
- `FULL_PASS`: requires both legs PASS, same-vintage PASS, source provenance/raw-byte and unit/sign/period acceptance, and no unresolved scope issue.
- `BLOCKED`: current named route/access dependency prevents required capture. It does not mean the data do not exist.

## Acceptance rule

No country is marked `FULL_PASS` in this initial consolidated matrix. Numeric agreement at published rounding is not a vintage pass. A country may have one or both numeric legs passing while remaining partial due to vintage, raw national bytes/hash, exact source scope, sign/scale, or external custodian limitations. Do not aggregate until the pre-registered inclusion rule and all required country gates pass.

## Limitations / next reconciliation

This first matrix consolidates the immutable cohort, current registry/queue and country report search results. It is not yet a line-by-line re-audit of every historical report version. In particular, rows marked `DATA_CAPTURED` with a pending vintage or raw-byte gate must not be promoted. Some older report summaries may be superseded by later continuations; always use the latest country continuation before changing a gate. The next update should attach a report ref and exact evidence blob/source receipt to every non-NOT_STARTED row and reconcile older country reports with the latest continuation.
